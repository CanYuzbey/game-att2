## Diagnostic conclusion

The existing sources support source-limb invalidation, affordability for defined actions, action-economy/status legality, and player Blood/limb consequences. They do not support Warden anatomy, resource costs, defeat, surrender, escape, or personality. A future owner-approved Encounter 3 model must define the smallest bounded target/response surface and then trace each attack through state mutation and capability recomputation. No row above is a canonical outcome.
