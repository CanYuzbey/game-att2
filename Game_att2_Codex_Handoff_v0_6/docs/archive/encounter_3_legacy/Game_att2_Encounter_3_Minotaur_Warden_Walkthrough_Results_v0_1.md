# Minotaur Warden Paper Walkthrough Results v0.1

Designer-run matched paper evidence only. It does not prove fun or human-player behavior.

## Coverage

Twenty core walkthroughs were planned and walked using the packet: five table paths x Known/Unknown x Script A/B. The same roll sequence was used within each script pair. Loan debt was settled after round four.

| Path | Known A | Known B | Unknown A | Unknown B | Repeated observation |
|---|---|---|---|---|---|
| Integrate | arm pressure readable; Guard works | arm safe from Unstable | cost regret when Hook is not first | stable but lower Blood | situational arm protection |
| Repair | lower initial Bleeding risk | Cleave still needs medical decision | cost regret if Cleave roll misses | torso value noticed after visible Cleave | situational torso protection |
| Strengthen | Brace cancels first Charge | later Charge causes Stand | useful when Charge known | valid gamble when unknown | one lost action prevented |
| Leave | Blood funds Guard/Cream | Blood absorbs tempo loss | defensible conservative path | strongest uncertainty reserve | resource compensation |
| Loan | immediate reserve | debt settles after survival | distinct debt regret | debt can fail independently | not free value |

## Findings

- Charge, Cleave, and Horn Hook have distinct readable purposes.
- Strengthened Legs visibly prevent the first tempo loss, but do not solve later Charge; this is situational value.
- Repair changes the first Cleave's Bleeding likelihood and treatment demand, but the 18-Blood cost warrants later numerical review rather than a change now.
- Integration is strongest when Horn Hook arrives before the player can stabilize an Unstable graft; it is not automatically correct under Unknown information.
- Leave is defensible because retained Blood funds Guard and medical timing.
- Loan creates a separate debt risk after combat and is not free survival value.
