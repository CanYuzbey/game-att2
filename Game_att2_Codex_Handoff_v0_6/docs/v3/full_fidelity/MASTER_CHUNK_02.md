# Combat and Action Economy V3 — Full

**Status:** ACTIVE PAPER RULES + OPEN NUMERICS

## 1. Round sequence — V3 baseline

```text
A. start-of-round forced effects / scheduled consequences
B. Brain/Attention Decision Refresh where lifecycle says so
C. visible hostile intent / threat cue state
D. bounded Attention steering if available
E. choose/lock up to one Preparation
F. resolve Preparation
G. choose/lock up to one Main
H. resolve atomic Main
I. resolve incoming automatic/intercept/reflex events as triggered
J. update wounds/Blood/Will/capability
K. end-of-round expiry, anti-stall/continuation checks
```

Exact ordering between some preparation/intent/refresh details remains V3-1 implementation work.

## 2. Main/Preparation budget

- exactly zero or one Preparation opportunity may be committed;
- exactly zero or one Main opportunity may be committed;
- Attention slots never grant extra plays;
- Readied Item uses its authored Preparation/Main timing;
- at most one voluntary inventory-origin action executes per round.

## 3. Action lifecycle

### Preview
No mutation.

### Lock/commit
Revalidate source/target/cost/timing.

### Execution
Apply authored atomic chain.

### Completion
Recompute source/capability/card access.

### Cancellation
If pre-execution commitment becomes illegal:
- no invented substitute;
- no alternate source;
- no alternate target;
- unpaid execution-time cost remains unspent;
- action tempo treatment follows explicit contract.

V3-1 must choose exact lock/cancel tempo semantics where still open.

## 4. Source condition

A card/action declares minimum source state.
Below minimum:
- Dormant/Invalid;
unless a Strained/Desperate profile explicitly exists.

V1's generic 100/75/50% source multiplier is preserved as legacy evidence only.
V3 prefers authored local degradation axes.

## 5. Targeting

Offensive physical techniques select target body region before commitment.

Preview:
- legality;
- expected structural/wound consequence class;
- dependent capability;
- whether limb reward may be endangered.

## 6. Basic attack vs premium transferable part

The V1 exploit-prevention principle remains active:
ordinary/free/basic damage may disable/ruin without automatically producing premium clean-transfer anatomy.

V3 does not yet lock:
- Claim the Cut;
- Bone Scissors;
- Hell Saw;
- exact Clean/Stressed/Ruined generation values.

Those remain legacy mechanics / possible future fixtures.

## 7. Defense

### Yellow
Block or Parry.

### Red
Evade only.

No color-only communication.

### Block
Choose a different legal guarding source where required.
Final recipient becomes guarding source.
It takes previewed structural consequence.
No hidden fallback limb.

### Parry
Narrow timing.
Success prevents the incoming physical package according to current paper rule and changes Will.
Miss applies original attack; no extra secret miss penalty.

### Evade
Success prevents Red consequence.
No range/reposition state created.
