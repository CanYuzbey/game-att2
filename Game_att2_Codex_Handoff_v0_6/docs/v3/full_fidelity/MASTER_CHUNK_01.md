# V3 Authority and Supersession Contract

**Status:** BINDING

## 1. Core promise

> I survived by sacrificing and rebuilding my body; the body I built changed how I could fight.

Priority:
1. sacrifice / Blood desperation;
2. bodily transformation;
3. anatomical tactics;
4. card/build richness.

## 2. V3 authority layers

```text
Causal Kernel
→ Body / Physical Capability
→ Concept Deck
→ Brain Architecture
→ Attention
→ Player Interaction
→ Encounter / World
→ Persistence / Evidence
```

Cards, Brain, Attention, NPC scripts, UI, and content cannot overwrite body/state truth.

## 3. Status vocabulary

- **BINDING V3** — owner-approved and active.
- **INHERITED ACTIVE** — owner-approved V1/V2 direction still compatible with V3.
- **ACTIVE DOWNSTREAM** — still active direction, but not required in the current gate.
- **PAPER RULE** — coherent active contract; runtime implementation requires a gate.
- **WORKING HYPOTHESIS** — falsifiable comparison, not final.
- **RESEARCH NUMERIC** — exact value retained for comparison only.
- **LEGACY EVIDENCE** — historical implementation/test result; no active gameplay authority.
- **SUPERSEDED** — explicitly replaced.
- **REJECTED ACTIVE** — intentionally excluded from current V3.
- **OPEN** — unresolved; do not fill silently.

## 4. Universal causal contract

```text
prior explicit state
→ source / ownership / target / timing legality
→ approved rule + injected randomness
→ atomic mutation
→ recompute physical capability
→ recompute card / Concept legality
→ recompute Brain/Attention eligibility
→ forced consequences
→ motivation-supported legal response
→ state-derived continuation / surrender / death / escape
→ structured evidence
```

## 5. Non-negotiable invariants

- legality precedes probability;
- exact sources are required;
- no silent source substitution;
- rejected actions do not pay uncommitted cost or consume an action;
- started atomic actions finish under their declared chain;
- configuration changes numbers, not mechanic meaning;
- randomness is injectable/seedable in evidence builds;
- domain state changes are logged;
- scripts choose among legal options rather than selecting endings;
- replacing an identity-sacrificed limb restores capability, not history;
- human-experience claims require human evidence.

## 6. Source supersession rules

### V1 simulator
Retained as:
- engineering architecture evidence;
- deterministic test/evidence model;
- legacy mechanic fixtures;
- negative/exploit cases.

Not retained automatically as:
- V3 combat cadence;
- V3 item values;
- V3 enemy content;
- V3 balance;
- V3 product implementation.

### V2 living design
Retained where V3 does not explicitly replace it.

### V3 owner amendments
Override V2 where changed, especially:
- Brain Architecture now participates in access rather than being only a hand interpreter;
- tactical class guarantees are allowed/desired;
- Attention selection explicitly combines Brain bias, limb distribution, recency, source state and Concept bias;
- extreme source specialization is intentionally legal;
- chosen sacrifice is elevated above card richness;
- transformation cost is multi-channel rather than one global instability/corruption score.

## 7. No information-loss rule

If a historical detail is no longer active, it belongs in a ledger with:
- source;
- old meaning/value;
- evidence status;
- why V3 does not activate it;
- what V3 uses instead;
- conditions under which it could be reactivated.

Deleting or summarizing away a meaningful old decision is not acceptable documentation practice.

# Development Master V3 — Full Fidelity

**Status:** BINDING MASTER SPEC

## 0. Purpose

This document consolidates the full known project system, not merely the current sprint.
It deliberately carries forward V1's coverage discipline and V2's product-facing decisions.

## 1. Maturity / gates

```text
V3-0 documentation & authority consolidation — PASS
V3-1 isolated combat sandbox — CURRENT
V3-2 body transition/graft consequence — DOWNSTREAM
V3-3 Blood/sacrifice economy — DOWNSTREAM
V3-4 same-boss alternate-body replay — DOWNSTREAM
V3-5 Underground City connected sample — DOWNSTREAM
vertical slice / production — NOT AUTHORIZED
```

## 2. Design pillars

### 2.1 Chosen Sacrifice
A meaningful player-chosen loss should be memorable and causally persistent.

### 2.2 Body as Build
Every important part must own action, passive, world capability, defense, physiology, economy, or meaningful drawback.

### 2.3 Blood as Volatile Bankroll
Blood is survival, economy, procedure currency and selected ability/emergency-control fuel.

### 2.4 Anatomical Combat
Target/source choices change future capabilities, reward options, defense and graft prospects.

### 2.5 Desperate Maintenance
Power can create treatment, maintenance, compatibility, world reaction, or coordination problems.

### 2.6 Ritualized Readability
Pre-commitment UI must communicate source, target, cost, risk, expected consequence class, and access/invalid reason.

### 2.7 Bounded Imperfect Access
Brain/Attention creates planning friction without making body capability meaningless.

## 3. Body topology

Current sample uses:
Head / Torso / Left Arm / Right Arm / Legs / Core.

Any topology expansion is expensive because it touches:
- card source contracts;
- targeting;
- wounds;
- animation;
- UI;
- save data;
- Brain/Attention pools;
- content;
- test matrices.

## 4. Source states and orthogonal facts

Never collapse all body facts into one status.

Track separately:
- existence / attachment;
- structural integrity/state;
- wound;
- treatment;
- graft origin;
- integration/compatibility;
- provenance when meaningful;
- capability tags;
- card-expression eligibility;
- reservation/occupation;
- maintenance.

V2 source-state vocabulary Intact/Damaged/Critical/Offline is conceptually retained.
V1 exact 70%/35% thresholds are **legacy numeric evidence**, not active V3 values.

## 5. Opportunity origins

Every opportunity has one primary origin:
- **Body**
- **Inventory**
- **State-required**
- **Automatic**

This V2 taxonomy is inherited and active because it remains compatible with V3.

Origin cannot change to bypass timing/source/ownership.

## 6. Voluntary action economy

PAPER RULE:
- 0–1 Preparation;
- 0–1 Main;
per ordinary actor/round.

Automatic responses execute within a resolving event, not as bonus voluntary plays.

One voluntary inventory-origin action per round is inherited from V2.

## 7. Body cards

The body creates exact physical expressions.

A source may create several roles:
Attack / Defence / Control / Preparation / Recovery, etc.

Typical V3 authoring guardrail:
- simple source: 2–3 expressions;
- primary combat source: 3–5;
- rare complex source: up to ~5–6 if justified.

V2 diagnostic cap "max 5 cards per exact source" is preserved as a **research bound**, not production law.

## 8. Abstract card concepts

INHERITED ACTIVE:
The complete abstract concept vocabulary is known from the beginning.

The body determines whether a physical expression of a concept is currently possible.

Death does not unlock or fabricate a "Memory Card".

## 9. Concept Decks

INHERITED ACTIVE, DOWNSTREAM FOR V3-1:
- earned through authored achievements/equivalent non-boss milestones;
- persist across attempts/runs;
- provide playstyle chassis;
- perform atomic source-valid exchanges;
- incompatible expressions remain known/Dormant;
- missing/Dormant/Invalid sacrifice cannot purchase a live gain;
- dedicated special cards must still own physical source.
