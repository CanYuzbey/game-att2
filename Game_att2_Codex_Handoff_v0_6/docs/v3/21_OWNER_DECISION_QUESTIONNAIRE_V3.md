# Game att2 — V3 Owner Decision Questionnaire v0.1

Status: ACTIVE OWNER-DECISION INPUT DOCUMENT.

The questionnaire is deliberately separated into two sequential files so it remains easy to review and edit in Git while preserving one ordered form:

1. [Part 01 — Q1–Q20: identity, sacrifice, surrender, Brain/Concept/items](questionnaire/OWNER_DECISION_QUESTIONNAIRE_PART_01.md)
2. [Part 02 — Q21–Q45: first playable, world, presentation, product/commercial](questionnaire/OWNER_DECISION_QUESTIONNAIRE_PART_02.md)

Fill them **in order**. The sequence is designed to move from independent to dependent, simple to complex, and small-scope to large-scope decisions.

The standalone DOCX generated from the same content is the preferred human form-filling artifact. Numeric balance, timings, thresholds, probability weights, temporary fixture values, code/module architecture, test sample sizes, CI/tooling, optimization, and other reversible professional choices are intentionally excluded from owner questions unless later evidence shows they materially alter product identity.
