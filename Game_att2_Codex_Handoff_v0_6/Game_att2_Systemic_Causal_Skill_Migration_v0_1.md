# Game att2 Systemic Causal Skill Migration v0.1

## Migration record

| Area | Old behavior | New behavior |
|---|---|---|
| Action resolution | Validate/resolve approved mechanics, often inside narrow encounter scripts | Mandatory causal loop validates, mutates state, recomputes capabilities, evaluates consequences, then permits script/behavior selection |
| Encounter design | Could begin with intended pressure sequence or victory test | Begins with state, objectives, action sources, constraints, vulnerabilities, and viable conclusions |
| Acceptance | Rules, logs, scenarios, and outcomes tested | Adds traceability from prior state through capability/affordance changes and termination/deferred checks |
| Hostile review | Scope, architecture, evidence, and rule drift | Adds hard-coded answers, script immortality, resource theatre, decorative limbs, outcome teleportation, fake emergence, and invented biology/behavior |
| Undefined rules | Reversible implementation ambiguity could be configured | Identity-defining anatomy, psychology, surrender, escape, and systemic scope require owner authorship; technical interpretations remain minimal and labeled |

## Files and compatibility

- Added `docs/11_SYSTEMIC_CAUSAL_DESIGN_SKILL_v0_1_CODEX.md` with the causal loop, taxonomy, anti-patterns, and templates.
- Amended `docs/09_PRODUCTION_OPERATING_SKILL_v4_1_CODEX.md` additively; its evidence, source-precedence, AI quarantine, scope, and maturity controls remain active.
- Added assimilation and non-canonical Minotaur audits; updated README navigation and the decision/project-state record.

Compatibility: existing deterministic simulator behavior and config are unchanged. Small explicit encounter scripts remain valid as test drivers or authored preferences when they select only legal actions and yield to state-derived capability loss and forced consequences. No generic AI, anatomy, or simulation framework is required.

## Limitations and revisit conditions

The skill cannot resolve missing canonical rules. Revisit when an approved runtime Encounter 3 target/response model exists; new represented anatomy is approved; actor intent/surrender/escape definitions are authored; or repeated special cases indicate the controlled taxonomy is insufficient. Any expansion must remain finite, testable, and source-backed.
