# Minotaur Designer Self-Play Protocol v0.1

## Evidence classification

```text
DESIGNER SELF-PLAY EVIDENCE
Participant count: N=1
Participant: project owner/designer
Repeated conditions: 4
Independence: low
Prior system knowledge: high
Learning contamination: unavoidable
Suitable for: flow, arithmetic, obvious ambiguity, personal experience, gross balance problems
Not suitable for: population comprehension, natural preference distribution, accessibility, onboarding validation, general fairness claims
```

This fallback does not validate Encounter 3 for a general audience, prove fun, open implementation, or open Unity.

## Session rules

- `SELF-S01` through `SELF-S04` are all Can, not four participants.
- Each session receives exactly one private randomized condition.
- Reveal only participant-facing cards, current state, current telegraph, public roll, and current outcome.
- Do not reveal scripts, future attacks, other-session results, intended preparation purpose, or the complete condition order.
- Can chooses table options freely; do not select for coverage.
- Record actual separation: `same sitting`, `short break`, `long break`, or `separate day`.
- Before each session remind Can to choose from current presented state, not merely to cover an option; prior knowledge remains recorded contamination.

## Facilitator opening

"The system is being tested, not you. There is no correct choice. Please answer as a player rather than as the designer where possible, and think aloud if comfortable. Your designer knowledge and any knowledge from earlier sessions will be recorded as a limitation."

At the table, record selected option, exact stated reason, expected threat, expected benefit, confidence 1-5, decision time, clarification, and prior-session influence. During play use the paper encounter verbatim, read telegraphs verbatim, roll openly, and request one decision at each actual choice. Never give strategic hints or alter an outcome.

## Debrief and stop rule

Ask all 14 approved questions in the session template before explaining design purpose. Record fairness, clarity, agency, and table usefulness from 1-5. End the session. Do not analyze between sessions. Start another session only after Can types `START NEXT SESSION`.

## After all four primary sessions

Keep free-choice and any later `DIRECTED DESIGNER COVERAGE` separate. Do not begin directed coverage without explicit approval. Analyze only after all four sessions, separating observed fact, Can statement, facilitator interpretation, design inference, and recommendation.

Production gates remain: `ENCOUNTER 3 PRODUCTION IMPLEMENTATION BLOCKED`; `UNITY BLOCKED`.
